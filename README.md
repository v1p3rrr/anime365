# Anime365 Downloader

Каталог Anime365, загрузка видео и субтитров в существующую Jellyfin-библиотеку с автоматическим
маппингом на уже скачанное и корректным именованием файлов.

> **Статус: работает целиком.** Тестов 787.
> Детально: [claude/04-feature-matrix.md](claude/04-feature-matrix.md) ·
> [claude/10-progress.md](claude/10-progress.md)

## Что уже работает

Загрузка проверена на живом API: видео скачивается целиком (87.7 МБ, валидный MP4),
субтитры раскладываются с именем, совместимым с Jellyfin.

- Каталог из 29 231 тайтла: виртуализированная сетка, поиск (локальный и на сайте),
  фильтры по жанрам, типу, году, сезону, оценке; отдельная вкладка онгоингов
- Страница тайтла: описание, эпизоды, сводка переводов с покрытием серий диапазонами,
  определение вшитых субтитров, оценка доступного качества
- Панель загрузки под строкой серии: переводы разложены по типам, недостающее впереди,
  уже закрытое вашими файлами — под кнопкой. Что считать закрытым, решает язык звуковой
  дорожки локального видео
- Сканирование библиотеки и сопоставление папок с тайтлами, включая разведение сезонов
  по дате премьеры; ручная привязка папок и отдельных серий; слежение за файловой системой
- Скачивание видео и субтитров: очередь с докачкой по Range, ретраями, паузой и отменой;
  отдельный воркер постобработки; живой прогресс через SSE; батч-загрузка всех серий автора
- Именование по правилам Jellyfin: релиз-группа заменяется на `anime365_{автор}`,
  источник всегда `WEBDL`, субтитры получают basename существующего видео
- Просмотр в браузере на Artplayer: жесты на мобильных, горячие клавиши, скорость,
  картинка в картинке, кнопка показа-скрытия субтитров. Видео идёт через наш прокси
  (премиум-токен в браузер не попадает), ASS-субтитры рисует libass в WebAssembly
- Скачивание себе на компьютер: видео идёт прямо с CDN мимо сервера (токен при этом
  не покидает сервер), субтитры и уже скачанные файлы — с сервера
- Фонотека: извлечение звуковой дорожки ffmpeg в отдельный корень вне библиотеки,
  прослушивание прямо в браузере — на странице тайтла и отдельной вкладкой в библиотеке
- Страница настроек с тремя слоями (по умолчанию → ENV → интерфейс), пароль на вход,
  CSP/CSRF, ограничение частоты запросов
- Интерфейс на трёх языках (русский, English, 日本語), светлая и тёмная темы
- Связи между сезонами через Шикимори, в порядке просмотра, а не по дате релиза
- Фоновый сбор сведений о том, какие переводы вообще есть на сайте, — и фильтр каталога
  по ним; данные о непроверенных тайтлах под фильтр не подпадают
- Работа через прокси или VPN стандартными `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`
- Своя папка для отдельной серии — с предупреждением, что батч разложит её не туда,
  куда остальные (назначается пока только через API)
- Переход на страницу тайтла в Anime365 и в Jellyfin: тайтл находится у Jellyfin
  сопоставлением по пути, настраивать трансляцию путей не нужно
- Отчёт «что Jellyfin не распознал»: показывает файлы, которые лежат на диске и
  видны нашему сканеру, но у Jellyfin не подобрались — обычно из-за именования
- Состояние каталога в адресе страницы: «назад» со страницы тайтла возвращает к
  тем же фильтрам и странице, а подборкой можно поделиться ссылкой
- Языки звуковых дорожек по ISO-справочнику, с названием языка в подсказке
- Пользователи и права: вход по логину и паролю, пять прав (каталог, просмотр,
  загрузки, библиотека, настройки), защита последнего администратора. Каждый
  эндпоинт спрашивает право, а интерфейс не рисует то, на что прав нет
- Каталог отвечает за миллисекунды: запросы идут по покрывающим индексам, а не
  сканируют широкую таблицу. Возврат на страницу не перезагружает данные

## Быстрый старт

Целевая платформа — **Ubuntu Server** с Docker. Разработка возможна и на Windows
(достаточно задать `A365_DB_PATH`), но рассчитано всё на Linux.

### Перед первым запуском: лимит inotify

Приложение следит за файловой системой, чтобы библиотека в UI была актуальной без ожидания
расписания. Каждый отслеживаемый каталог занимает одну inotify-watch. Проверьте лимит:

```bash
cat /proc/sys/fs/inotify/max_user_watches
```

На современной Ubuntu там 65 536 — этого хватает с большим запасом (библиотека из ~500 тайтлов
с сезонными подпапками это 1–2 тысячи каталогов). Если значение 8192 и в логах появится
предупреждение об откате на расписание, поднимите лимит:

```bash
echo "fs.inotify.max_user_watches=262144" | sudo tee /etc/sysctl.d/99-inotify.conf && sudo sysctl --system
```

Учтите: Jellyfin и Sonarr тоже расходуют watch'и из общего лимита пользователя.
Если медиа лежит на **сетевой ФС** (NFS, SMB), слежение работать не будет — события от других
хостов не доставляются. Приложение это обнаружит, откатится на расписание и покажет статус в UI;
в таком случае уменьшите `A365_LIBRARY_SCAN_HOURS` с 24 до 4–6.

```bash
cp .env.example .env
```

Заполните в `.env` минимум:

| Переменная | Зачем |
|---|---|
| `A365_ACCESS_TOKEN` | токен аккаунта с премиум-подпиской, без него скачивание не работает |
| `A365_UI_PASSWORD` | пароль на вход в UI |
| `A365_SERIES_ROOT`, `A365_MOVIES_ROOT` | пути **внутри контейнера** (менять обычно не нужно) |

Поправьте в `docker-compose.yml` пути к медиа в секции `volumes` — слева хостовые, справа те,
что указаны в `A365_SERIES_ROOT` / `A365_MOVIES_ROOT`.

```bash
docker compose up -d
```

UI: `http://localhost:8080` · Проверка: `curl http://localhost:8080/api/health`

### Где взять токен

1. Зарегистрируйте приложение на `/api-clients` вашего зеркала Anime365 — получите `app`.
2. `GET /api/login?app=ВАШ_APP&email=...&password=...` → `access_token`.

Токен бессрочный (до смены пароля). Наружу приложением не отдаётся и вырезается из логов.

## ⚠️ Безопасность

По умолчанию сервис слушает **только `127.0.0.1`**. Это осознанно: через UI доступен ваш
премиум-токен и запись в файловую систему сервера.

- Для доступа из локальной сети — замените порт на `0.0.0.0:8080:8080` **и задайте пароль**.
- Наружу — только через VPN (Tailscale/WireGuard) либо через Nginx с внешней авторизацией
  (Authelia / basic auth) поверх встроенного пароля.

Полный разбор рисков и мер: [claude/07-security.md](claude/07-security.md)

## Настройки

Три слоя, приоритет по возрастанию:

```
значение по умолчанию (код)  <  переменная окружения  <  правка в UI
```

Все настройки объявлены в одном месте — `backend/app/core/settings_registry.py`. Оттуда же
генерируются `.env.example` и форма в UI, поэтому они не могут разойтись. В UI у каждого поля
видно, откуда взято значение, и есть кнопка сброса.

Перегенерировать `.env.example` после правки реестра:

```bash
cd backend && python -c "import sys;sys.path.insert(0,'.');from app.core.settings_registry import render_env_example;open('../.env.example','w',encoding='utf-8',newline='\n').write(render_env_example())"
```

## Разработка

```bash
cd backend && pip install -e ".[dev]" && uvicorn app.main:app --reload --port 8080
```

```bash
cd frontend && npm install && npm run dev
```

Фронт на `:5173` проксирует `/api` на `:8080`. Продакшен-сборка кладётся в `backend/app/static`
и раздаётся самим FastAPI — отдельного контейнера с Nginx нет.

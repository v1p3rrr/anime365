# Разбор маппинга на живой библиотеке (2026-08-04)

Пользователь сказал: «очень много папок смаппилось криво». Здесь — что именно
криво, почему, и что из этого следует для алгоритма. Правки по итогам ещё **не
сделаны**: файл заведён, чтобы чинить всё разом и по фактам, а не по одному
случаю.

## Как измерено

Сервер `bocchi@192.168.1.76`, **только чтение**: `ls`/`find`/`grep` по
библиотеке и снимок базы, скопированный внутрь одноразового контейнера
(`-v …/data:/data:ro` + tmpfs). Файлы пользователя не менялись.

Данные: развёрнутая версия — коммит `333a487`, то есть до правок этой сессии.

| корень | папок | привязано | без привязки, но с видео | видеофайлов |
|---|---|---|---|---|
| `/media/anime/library` | 317 | 247 | **0** | 2104 |
| `/media/anime_movies/library` | 55 | 54 | **0** | 52 |

⚠️ Важный вывод из последнего столбца: **непривязанных папок с содержимым
нет**. Проблема не в том, что чего-то не хватает, а в том, что привязки
**неверные** — а такая ошибка не видна, пока файл не уедет не в ту папку.

Ещё цифра: **33 тайтла держат больше одной папки**, у `Girls Band Cry` их
восемь.

## Дефект 1. Подпапка наследует ID родителя, даже когда она не сезон

**20 папок.** Самый массовый случай.

`library_service.py` для любой дочерней папки берёт `.nfo` и название у
родителя:

```python
title_nfo = _nfo_of(parent) if parent is not None else _nfo_of(folder)
folder_name = parent.name if parent is not None else folder.name
```

А защита в `matcher.py` закрывает только один случай:

```python
if ctx.season_number not in (None, 1):   # ← None проскакивает
    return None
```

Jellyfin кладёт `season.nfo` **в каждую** подпапку, включая служебные, и у
служебных в нём нет `<seasonnumber>`. Поэтому `season_number is None`, ID
родителя принимается, уверенность 100%.

Что так смаппилось (все — на тайтл родителя):

| папка | видео | что это на самом деле |
|---|---|---|
| `Girls Band Cry/subtitles` | 0 | папка с субтитрами |
| `Girls Band Cry/ScreenShot` | 0 | скриншоты |
| `Girls Band Cry/subs2srs output` | 0 | выгрузка для Anki |
| `Girls Band Cry/EXTRA` | **39** | BD-сканы и бонусный диск |
| `Girls Band Cry/Movie 1 …`, `Movie 2 …` | 1, 2 | **два отдельных фильма** |
| `Fate+Zero/NC`, `/Bonus` | 4, 3 | безкредитные OP/ED и бонусы |
| `Bocchi the Rock!/LIVE` | 1 | концерт |
| `Bocchi the Rock!/Gekijou Soushuuhen … Movie` | 2 | **фильм-компиляция** |
| `Bang Dream!/Movies and OVAs` | 8 | фильмы и OVA |
| `Toradora!/Toradora 10th Anniversary 10bit` | 29 | другой релиз того же сезона |

Плюс один случай с номером сезона, который всё равно проскочил:
`Yuru Camp/[Ohys-Raws] Yuru Camp Season 2 …`.

**Что делать.** Различать «свой `.nfo`» и «унаследованный» и принимать ID
родителя только при `<seasonnumber> == 1`. Нет номера сезона — это не сезон, а
фильм, спешл или служебная папка, и родительский ID к ней отношения не имеет.
Название тоже наследовать нельзя: у `Movie 1 - Youth Rhapsody` есть шанс
попасть в настоящий фильм по своему имени, а под именем родителя — ноль шансов.

## Дефект 2. Битый `.nfo` у папки-контейнера протекает во всё поддерево

**7 папок на один неверный тайтл.**

`Evangelion/tvshow.nfo` описывает не сериал, а показ к 30-летию 2026 года:

```
<title>Evangelion: Housou 30 Shuunen Kinen Tokubetsu Kougyou
<anilistid>204270      ← показ 2026 года
<shikimoriid>30        ← а это настоящий NGE 1995
```

Jellyfin сматчил папку-франшизу на этот показ. Дальше по наследству:
`Evangelion/Season 1` — **26 серий оригинального сериала** — сел на показ, и
все четыре папки фильмов тоже.

Два отдельных следствия:

* **в одном файле два ID, указывающие на разные тайтлы**, и `anilistid`
  побеждает молча. Противоречие — это сигнал «данные ненадёжны», а не повод
  выбрать первый попавшийся;
* **никто не проверил правдоподобие**: у папки 26 видеофайлов, у кандидата
  один эпизод. Такое совпадение обязано отвергаться.

## Дефект 3. Внешние ID самого Anime365 местами неверны

Это оказалось хуже дефекта 2, потому что бьёт по папкам **с** правильным `.nfo`.

| папка | `.nfo` | куда село | как |
|---|---|---|---|
| `Your Name` | `anilistid 97962` (настоящий ID «Твоего имени») | **«Suntory Minami Alps no Tennensui»** — реклама воды | anilist_id, 100% |
| `A Silent Voice - The Movie` | `shikimoriid 40102` | «Meitantei Conan Magic File 2» | mal_id, 95% |
| `Kagerou Daze - In a Day's` | — | «Sekai Saikou no Ansatsusha…» | mal_id |
| `A Certain Magical Index - Miracle of Endymion` | — | «Tensei Kizoku no Isekai Boukenroku…» | mal_id |

Проверено: дублей `anilist_id` в каталоге всего 2 группы, нулевых нет — то есть
дело не в нашем индексе. Значит **в каталоге Anime365 у части записей проставлен
чужой `anilistId`**, и слепое доверие ему даёт грубые промахи.

Отдельно: у `mal_id` проверка названия (`_title_agrees`) **есть**, и она всё
равно пропустила «A Silent Voice» → «Conan Magic File 2». Порог 75 по
`token_sort_ratio` против **всех** вариантов из `allTitles` слишком мягок: у
популярных тайтлов вариантов десятки, и какой-нибудь да совпадёт.

**Что делать.** Проверку названия распространить и на `anilist_id`, а саму
проверку ужесточить: сверять с основными написаниями (`titles`), а не со всем
`allTitles`, и поднять порог. Плюс сверка года и типа: фильм 2016 года не может
оказаться рекламой 2013-го.

## Дефект 4. Сезоны сериала слипаются в один тайтл

`Monogatari` разложен на шесть сезонов; `Season 4` сел на `Bakemonogatari`
(первый сезон) по `exact_title` 99, `Specials` — туда же по `premiered`.
`Honzuki no Gekokujou S1+S2+S3 x265 10bit` — семь папок на один тайтл, из них
`Season 1` (39 видео) село на **OVA** с одним эпизодом.

Причина та же, что у дефекта 1, плюс: когда каскад C не находит сезон по
кварталу премьеры, управление уходит в строковый каскад B, а тот сравнивает
название **родителя** и находит первый сезон. Номер сезона при этом не
учитывается вовсе.

**Что делать.** Если у папки есть `<seasonnumber> > 1`, результат каскада B,
указывающий на тайтл первого сезона, принимать нельзя — это заведомо не он.

## Дефект 5. Служебные папки вообще не должны мапиться

`subtitles`, `ScreenShot`, `subs2srs output`, `NC`, `Bonus`, `EXTRA`, `op ed`.
После правил из дефекта 1 они останутся непривязанными сами собой — и это
верный исход: лучше пусто, чем неверно. Проверить, что они при этом не начнут
засорять отчёт «нераспознанные папки»: у них нет видео, кроме `EXTRA`.

## Дефект 6. Мелочи, замеченные попутно

* `Girls Band Cry\Season 1` — папка верхнего уровня, в имени которой
  **обратный слэш**: чей-то копировавший скрипт сделал из пути имя. Сейчас она
  мапится как обычная папка;
* `subs only`, `subs only/AZUMANGA SUB`, `subs only/[Hi10][BD][720p]Amagami SS`
  сели на «Tokimeki Memorial: Only Love» по `anilist_id` — тот же дефект 1,

* `Steins;Gate` и `Steins;Gate 0` (две разные вещи) сели на один тайтл;
* `EVANGELION-3.0(-46h)` и `Evangelion - 3.0 You Can (Not) Redo` — **это

## Корпус для тестов

Брать эти случаи целиком, с настоящими `.nfo`:

| случай | чем проверяет |
|---|---|
| `Girls Band Cry` (8 папок) | наследование ID служебными папками и фильмами |
| `Evangelion` | битый `.nfo` контейнера + противоречие anilist/shikimori + правдоподобие по числу серий |
| `Monogatari` (6 сезонов) | сезоны не слипаются |
| `Honzuki … S1+S2+S3` | сезоны внутри релизной папки |
| `Your Name`, `A Silent Voice` | неверный внешний ID в каталоге Anime365 |
| `EVANGELION-3.0(-46h)` + `Evangelion - 3.0 …` | две копии одного фильма — обязаны остаться |
| `Genshiken/Season 1` → «Gendai Shikaku Bunka Kenkyuu Kai» | **верный** матч с низкой похожестью: другая романизация. Ужесточение порогов не должно его сломать |

## Порядок правок

1. дефект 1 (наследование) — он же даёт 20 из ~30 неверных привязок;
2. дефект 3 (сверка ID по названию, году и типу) — самые грубые промахи;
3. дефект 2 (правдоподобие по числу серий, конфликт ID);
4. дефект 4 (номер сезона против результата каскада B);
5. перепроверить на этой же библиотеке и сравнить «до/после» по числу папок,
   у которых привязка изменилась.

## Отдельно: имена субтитров

Замечание пользователя: у видео в имени есть `1080p`, у субтитров к нему нет,
из-за чего плееры не подхватывают их автоматически. Код ещё не смотрел —
`services/naming.py`, ветка «сабы к уже существующему видео» против ветки
«качаем видео и сабы одной пачкой». Во втором случае имя видео строится с
меткой качества, а имя субтитров — по образцу соседа без неё.

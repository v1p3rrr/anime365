# Правила именования файлов

Цель — чтобы Jellyfin распознал скачанный файл как **нужную серию нужного тайтла с нужным языком**,
и чтобы имя не выбивалось из того, что уже лежит в папке.

## Что отдаёт Anime365

- Видео: `content-disposition: attachment; filename="[Anime365] {romaji} - {NN} (t{translationId}).mp4"`
  Пример: `[Anime365] Sousou no Frieren - 06 (t4505262).mp4`
- Субтитры: `content-disposition` **отсутствует**, формат `.ass`, имя формируем сами.

Такие файлы уже есть в библиотеке пользователя (папка `Uma Musume … Shin Jidai no Tobira`),
то есть это результат работы штатного загрузчика сайта.

---

## Правило 1. Скачали ВИДЕО в существующую папку

Берём паттерн соседних файлов и заменяем в нём релиз-группу.

```
Zombie Land Saga S02E05 - Little Bodda Bope SAGA [neoHEVC] Bluray-1080p.mkv    ← сосед
Zombie Land Saga S02E05 - Little Bodda Bope SAGA [anime365_SebiVoice] WEBDL-1080p.ru.mp4   ← наш
                                                 ^^^^^^^^^^^^^^^^^^^^  ^^^^^         ^^^
                                                 группа заменена       WEBDL         язык
```

Что меняется, а что нет:

| Часть имени | Откуда берётся |
|---|---|
| `{Show} S{ss}E{ee} - {Episode Title}` | **структура соседа** (или каноническая схема, если соседей нет) |
| `[{Группа}]` | **заменяется** на `[anime365_{Автор перевода}]` |
| метка источника | **всегда `WEBDL-{height}p`**, даже если у соседа `Bluray-1080p` / `HDTV-1080p` |
| языковой суффикс | `.ru` / `.en` для озвучек; для `raw` и японского — **ничего** |
| расширение | как пришло с Anime365 (`.mp4`) |

Почему `WEBDL` всегда: всё, что приходит с Anime365, — это WEBDL, и врать в имени файла не будем
(решение пользователя, [D-05](09-decisions.md)).

### Если соседей нет (новая папка)
Каноническая схема:
```
{Show} S{ss}E{ee} - {EpisodeTitle} [anime365_{Автор}] WEBDL-{height}p{.lang}.mp4
```

### Фильмы
Схема Radarr, папка в корне фильмов:
```
{Title} ({Year}) - [WEBDL-{height}p] [anime365_{Автор}]{.lang}.mp4
```

## Правило 2. Скачали ТОЛЬКО СУБТИТРЫ к существующему видео

⚠️ Здесь правило замены группы **не применяется**. Jellyfin подхватывает сабы только при
совпадении basename с видеофайлом, поэтому basename берётся **как есть**, вместе с чужой
релиз-группой и чужой меткой `Bluray`.

```
Zombie Land Saga S02E05 - Little Bodda Bope SAGA [neoHEVC] Bluray-1080p.mkv                    ← видео
Zombie Land Saga S02E05 - Little Bodda Bope SAGA [neoHEVC] Bluray-1080p.anime365_YakuSub.ru.ass ← наши сабы
```

Схема: `{basename видео}.anime365_{Автор}.{lang}.ass`

Вставка автора нужна, чтобы держать несколько переводов на один эпизод — иначе второй русский
перевод затирал бы первый ([D-06](09-decisions.md)).

### Сабы к эпизоду, у которого локального видео нет
Имя строится по канонической схеме, как если бы мы качали видео, но с расширением `.ass`:
```
{Show} S{ss}E{ee} - {EpisodeTitle} [anime365_{Автор}] WEBDL-{height}p.{lang}.ass
```
Тогда при последующей докачке видео имена совпадут сами.

## Языковые суффиксы

| Тип перевода | `typeKind` / `typeLang` | Суффикс видео | Суффикс сабов |
|---|---|---|---|
| Русская озвучка | `voice` / `ru` | `.ru` | — |
| Английская озвучка | `voice` / `en` | `.en` | — |
| Русские субтитры | `sub` / `ru` | — | `.ru` |
| Английские субтитры | `sub` / `en` | — | `.en` |
| Японские субтитры | `sub` / `ja` | — | `.ja` |
| RAW (японский оригинал) | `raw` / `ja` | **ничего** | — |
| Прочие языки | `voiceOth` / `er` | **не качаем вообще** | — |

## Санитизация — обязательна

`authorsSummary` приходит **с внешнего сайта** и попадает прямо в имя файла. Это недоверенный ввод.

Реальные примеры авторов из API: `Crunchyroll [10bit]`, `YakuSub Studio (Aero)`, `EAC-3 2.0`,
`AniPlague`, `9volt`, `SubsPlease`, `SebiVoice`. То есть там уже встречаются скобки и точки.

Что делаем с именем автора перед вставкой:
- вырезаем `/ \ : * ? " < > |` и управляющие символы, NUL-байты;
- вырезаем `[` и `]`, чтобы не ломать разбор `[группы]` при следующем скане;
- схлопываем пробелы, обрезаем точки и пробелы на концах (Windows/SMB не любит хвостовые точки);
- ограничиваем длину;
- проверяем, что итог не совпадает с зарезервированными именами Windows (`CON`, `PRN`, `AUX`,
  `NUL`, `COM1…9`, `LPT1…9`) — библиотека может лежать на SMB-шаре.

Плюс общий лимит на полный путь и на длину имени файла (255 байт в ext4, но UTF-8 многобайтовый —
считаем в байтах, а не в символах).

## Коллизии

| Ситуация | Поведение |
|---|---|
| Файл с таким именем уже есть, размер совпадает | считаем скачанным, задачу закрываем как `already_exists` |
| Файл есть, размер отличается | не перетираем; добавляем ` v2` перед расширением и пишем предупреждение |
| Два перевода одного автора на одну серию | к автору добавляется `translation_id`: `anime365_AniPlague_5418036` |
| Уже лежит файл `[Anime365] … (t{id})` от штатного загрузчика сайта | распознаём по `t{id}` и **не качаем повторно** |

Последний пункт важен: в папке `Uma Musume … Shin Jidai no Tobira` уже лежат
`[Anime365] … - 01 (t5282068).mp4` и `(t5302072).ass` — приложение обязано понять, что эти переводы
уже скачаны, и не создавать дублей.

## Что не трогаем

Метафайлы Jellyfin оставляем в покое, никогда не удаляем и не переименовываем:
`tvshow.nfo`, `season.nfo`, `movie.nfo`, эпизодные `.nfo`, `*-thumb.jpg`, `folder.jpg`,
`backdrop.jpg`, `banner.jpg`, `landscape.jpg`, `logo.png`, `season*-poster.jpg`.

Своих `.nfo` тоже **не пишем** — этим занимается Jellyfin, и конфликтовать с ним смысла нет.

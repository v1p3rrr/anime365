## Что это за проект

Приложение для домашнего сервера: смотреть каталог Anime365, качать видео и субтитры по
премиум-API, раскладывать в существующую Jellyfin-библиотеку с правильными именами и маппингом
на уже скачанное.

- Библиотека: `~/media/anime/library/*` (сериалы), `~/media/anime_movies/library/*` (фильмы)
- Смотрится через Jellyfin, в перспективе рядом Sonarr/Radarr/qBittorrent
- Сервер слабый: 16 ГБ ОЗУ, низкая частота → приложение обязано быть лёгким
- Интересующие языки: **ru, en, ja** (остальные игнорируются)

## Стек (кратко)

Python 3.12 + FastAPI + SQLite(WAL) + SQLAlchemy 2.0 + APScheduler + httpx ·
React 18 + TypeScript + Vite + Mantine + TanStack Query/Virtual · один Docker-образ, один порт.

## Главное, что нельзя забыть

1. `GET /api/series` **без `fields` отдаёт всё** (включая эпизоды и описания) — мегабайты на страницу.
2`embed` всегда возвращает ссылки на `smotret-anime.org` независимо от зеркала → нужен rewrite хоста.
3. Пагинация переводов — **только `feed=id` + `afterId`**, иначе выдача врёт.
4. Хардсаб определяется только через `embed` (`subtitlesUrl == null` при `typeKind == "sub"`) → лениво.
5. `numberOfEpisodes` — это план, а не выложенное. Локальное число серий может быть больше.
6. Всё, что скачано с Anime365, в имени файла помечается **`WEBDL`**, даже если соседи `Bluray`.
7. Отметок «просмотрено» в API нет вообще.
